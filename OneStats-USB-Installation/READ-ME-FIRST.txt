IMPORTANT — WHAT THIS INSTALLER DOES AND DOES NOT DO:

  * It installs the OneStats APP only. It bundles the offline Microsoft
    WebView2 component, so it installs WITHOUT needing the internet.
  * It does NOT install PostgreSQL (the database) or the backend service.
  * So it is READY to use for an ADDITIONAL (CLIENT) computer that connects
    to an EXISTING OneStats server which already has the database.
  * It is NOT yet enough for a brand-new STANDALONE or MAIN-SERVER computer
    on its own, because the database/backend are not bundled. That packaging
    (the "sidecar") is a separate task still to be done.

It is also not code-signed yet, so Windows will show a SmartScreen warning;
choose "More info" -> "Run anyway" (code-signing needs a paid certificate,
a decision still pending).

This folder contains:

  * READ-ME-FIRST.txt ................ this file
  * INSTALL-GUIDE.txt ............... how to install, step by step
  * HOW-TO-BUILD-THE-INSTALLER.txt .. how the installer was built / rebuilt
  * PLACE-INSTALLER-HERE\ ........... the built installer + its checksum

-------------------------------------------------------------------
WHAT STILL HAS TO HAPPEN BEFORE A USB WILL WORK
-------------------------------------------------------------------

1. The installer must be BUILT on a Windows computer that has the build
   tools installed (see HOW-TO-BUILD-THE-INSTALLER.txt).

2. IMPORTANT LIMITATION: in its current form, the installer that those
   steps produce installs the OneStats APP ONLY. It does NOT yet install
   the database (PostgreSQL) or the background service automatically.
   That "installs everything by itself" behaviour is designed but has not
   been added to the build yet. Until it is, OneStats on a brand-new
   standalone PC still needs those parts set up separately, OR the PC must
   connect to an existing OneStats server that already has them.

3. Once the installer genuinely installs everything (or once you accept
   the app-only installer for "connect to a server" use), the finished
   installer file is copied into PLACE-INSTALLER-HERE\, and THEN this
   whole folder can be copied onto a USB stick.
